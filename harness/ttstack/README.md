# ttstack harness tree

This folder is generated from `ttstack/skills`, `ttstack/agents`, `ttstack/docs/harness/claude-code.md`, `ttstack/README.md`, `ttstack/plugin.json`, and the repository `LICENSE`. Do not edit it by hand.

Cursor uses `ttstack/` directly, and Claude Code installs `claude-code/`. A relative link to a ttstack file that the tree leaves out points at that file on GitHub `main` instead.

After editing those sources, run `node scripts/generate-ttstack-harness-trees.mjs` from the repository root and commit the result.
